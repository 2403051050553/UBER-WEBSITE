# Ride Booking Landing Page

A static, Uber-inspired landing page exploring a responsive ride-booking and driver recruitment experience.

## Built with

- HTML
- CSS
- Bootstrap 5

## Run locally

No build tools or package installation are required. Open `index.html` in a modern browser. Bootstrap, Font Awesome, and web fonts are loaded from external CDNs, so an internet connection is needed for those assets.

## Project files

- `index.html` — landing page markup
- `style.css` — custom page styling
- Local image and SVG assets — page illustrations and interface icons

## Scope

This repository is a front-end design exercise. It does not connect to Uber services, book rides, or process payments. The original design reference is available at [awaisetics.github.io/Uber-Clone](https://awaisetics.github.io/Uber-Clone/).
